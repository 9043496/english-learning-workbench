# 2.1 教学注入与批改接口（Muse / 任意被授权 agent）

这是当前接入规范，覆盖旧文档的 artifact 装配描述。
服务不绑定 Muse 身份。接手需要：授权、能访问 Mac 的受控地址、原 Bearer 凭证、符合字段格式。
凭证不在此包；通过既有私密渠道使用，不回显或放URL/日志。
当前教学地址 http://YOUR-PRIVATE-HOST:8765，仅其所在受控网络可达。
本机程序必须已启动；Mac休眠、离线、Tailscale路由/ACL均可能使远端不可达。

## 建议操作顺序与验收

1. GET /health 无鉴权，仅检查 build；应为 workbench-2.1-phone-20261018.3。
2. 带 Authorization: Bearer <私密凭证> GET /api/status/2.1、GET /api/records/inputs。
   401是未鉴权，连接拒绝/超时是服务或路由问题，不能混称“没连接”。
3. 先读已有记录和音频清单；沿用ID，不覆盖已有不同内容。新的正式教材用全新唯一ID。
4. 核对JSON与音频，先上传新音频，再 POST /api/import 导入教材。
   JSON上限8MiB，单音频128MiB。此步骤不是跨JSON/音频的整体事务，内容校验失败可能留下未引用音频；
   不重置数据库，修正后使用相同新key继续，不能覆盖已有不同字节。
5. GET回读导入ID与音频，记录实际HTTP状态/结果；打开当前Mac工作台刷新，确认内容出现。
6. David作答后点“上传学习数据”；agent读取 /api/coach/pending 与引用录音，人工批改；
   POST /api/coach/grades 字段级回写。David点“下载学习数据”取回反馈。
7. 远端成功必须由实际发起请求的 agent 提供结果。本机探测不冒充 Muse 云端验证。

## 教材音频的制作指导

按[当前规划书“语音生成指导”](2.1_需求与规划大纲.md#语音生成指导2026-10-19-david确认)制作：每篇按场景、文体和人物关系编写提示词；新声音风格先由David试听，同类已认可风格可按文章适配。
生活对话以2026-10-19已认可的日常语气v2为参照，其他文体按规划中的风格表处理。同篇角色声线一致，优先从全文演绎切句音；正文准确、英语清晰、自然连读弱读、适速、无背景音乐，不强行拉伸。
提示词、模型、角色声线映射、版本与试听反馈随学习包的制作档案一并交付；档案不包含凭证。听感认可与技术检查、目标设备验收分别记录。

## 需要教学方注入什么

| 内容 | 位置/字段 | 缺失时 |
|---|---|---|
| 正式文章、日期、标题、级别、词数 | inputs | 不自动编教材 |
| 全文音频 | inputs.audioKey | 提示音频未下发 |
| 逐句文本、中文译文、speaker、慢速句音 | sentences.items 或 inputs.sentences | 缺哪项提示哪项，句文本须和正文精确对应 |
| 全文单词/短语语境词义 | inputs.wordpack | 提示手动加词，不联网词典 |
| 理解、多义词题及正确答案、英文解析 | inputs.comprehension / polysemy | 不自动改造旧题 |
| 本篇3–5个旧词 | inputs.reused_vocab | 不显示重逢区 |
| 听写音频/原文/级别/词数 | dictation_tasks | 不自造任务 |
| 每月听说读写包 | inputs，type:level_test | 显示等待下发 |
| 实际作答和录音的批改 | coach/grades 写对应学习记录 | 显示待批改，不造分 |

## 接口总表

除 /health 外，以下均需 Bearer 或既有同源Cookie。ID/key完整作为一个URL组件编码，包括其中的斜杠。
- GET /api/records/{collection}：读集合；GET /api/records/{collection}/{id}：读单条，不存在返回null。
- POST /api/import：body为集合映射，如 {"inputs":[...],"sentences":[...],"dictation_tasks":[...]}。
  同ID相同内容跳过，同ID不同内容拒绝；教材普通记录PUT不能写。
- GET /api/blobs?prefix=...：清单；PUT /api/blobs/{key}：真实音频二进制；
  X-Blob-Meta = UTF-8 JSON {"mime":"真实音频MIME"} 的Base64；Content-Type为真实MIME。
  GET /api/blobs/{key}：音频二进制；GET /media/{key}支持Range（元素播放需要同源登录Cookie）。
  该操作员接口可覆盖同key，教学agent必须先GET比较并拒绝覆盖已有不同文件；新教材用新key。
- GET /api/coach/pending：progress/shadowing/vocab/inputs；不能只看日常记录而漏掉测试或句子没懂标注。
- POST /api/coach/grades：{"updates":[{"collection":"...","id":"...","grade":{...}}]}，整批事务。
- GET /api/sync/pull?since=<Unix毫秒>、POST /api/sync/push：设备学习同步，不用于教材注入。
- GET /api/sync/log：最近100条冲突。GET /api/export：私密数据备份，不应随源码分享。

Python 请求形式（环境变量由私密渠道提供）：
    import os, json, urllib.request
    base = os.environ["WORKBENCH_URL"].rstrip("/")
    token = os.environ["WORKBENCH_TOKEN"]
    req = urllib.request.Request(base + "/api/import",
        data=json.dumps(bundle, ensure_ascii=False).encode("utf-8"),
        headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
        method="POST")
    with urllib.request.urlopen(req, timeout=30) as response:
        result = json.load(response)
不要打印 token、完整 Request 对象或全部学生答案到公开日志。
代理环境如错误转发私网地址，需要在运行环境配置对应直连/NO_PROXY。

## 日常输入字段

inputs条目：
- id、date、title（可加title_cn）、body（段落字符串数组，或{text,speaker}数组；保留文章结构）。
- level、word_count、audioKey（准确对应已上传全文音频）。
- wordpack:[{w,pos,cn,phrase?,n?}]；phrase为字符串时按该短语匹配，n对应句号，可为单值或数组。
  按语境义提供，不凭词形猜释义。
- comprehension / polysemy：[{id,q,options:[{id,text}共4项],correct_option_id,explanation_en,sentence?}]。
  题干/选项/答案/解析为英文，polysemy保留句子语境；每组题号、选项ID唯一。
- reused_vocab：3–5个字符串，或{w}，或{vocabId}；建议使用{w,vocabId}，可离线显示并直接关联词库。
  不同词形不自动合并，短语作为一个单位；应真实在本篇正文出现。
- sentences可内嵌；也可单独集合{id:inputId,items:[{n,text,cn,speaker?,audioKey}]}。
  text与正文中的连续句子精确对应，否则本版不能凭语义推测句子位置。

dictation_tasks条目：
id/date/title/audio/source_text/level/word_count，可有inputId。
audio应为当前同源可播放URL，例如 /media/加密URL组件后的音频key；
提交前页面不显示source_text。实际教学原文由教学方提供。

## 水平测试包（字段结构，不含演示教材）

inputs内：
    {
      "id": "<新的唯一测试ID>", "type": "level_test",
      "date": "<YYYY-MM-DD>", "title": "<正式测试标题>",
      "score_scale": {"min": "<数值>", "max": "<数值>"},
      "sections": {
        "listening": {"audioKey": "<真实听力音频key>", "questions": ["<选择题对象>"]},
        "reading": {"body": ["<真实英文段落>"], "questions": ["<选择题对象>"]},
        "speaking": {"parts": [
          {"part":1,"questions":[{"id":"<题号>","text":"<实际英文提问>","audioKey":"<可选真实提问音频key>"}]},
          {"part":2,"preparation_seconds":60,"response_seconds":120,
            "task":{"id":"<题号>","text":"<实际题卡>","points":["<题卡要点>"],"audioKey":"<可选真实音频key>"}},
          {"part":3,"questions":[{"id":"<题号>","text":"<实际英文提问>","audioKey":"<可选真实音频key>"}]}
        ]},
        "writing": {"prompt":"<正式英文写作题>","word_limit":"<可选字数要求>"}
      }
    }
以上尖括号只是结构说明，不是可导入教材；min/max需真实数值，score_scale可省略。
听力/阅读question对象与上文选择题相同，四选一；所有听读/口语题号全包唯一。
口语无音频时仅用设备本地英语语音或显示文字，不通过在线TTS生成。
当前一包对应一次主尝试 level_test:<inputId>；提交后原作答冻结。
允许另一次测试应下发新ID，不覆盖已提交尝试。测试正确答案可以随包供教练参考，
但前端测试结果只显示教练回写的assessment，不自动推断水平。

## 学习记录与回写

- 日常 progress/inputId：保留学生原 answers、unknown_words、difficulty_self、sentence_flags 等。
  sentence_flags={"句n":"confused"}；取消补丁为null，合并后移除。没懂不等于错误答案。
- 日常题目批改grade：comprehension/polysemy下只可写correct/total/note/status/graded_at。
  不改变原answers或题目数量。i1_final仅hit/easy/hard，覆写说明用i1_overridden/i1_override_note。
- 跟读 grade：score:{fluency,pronunciation,completeness,note}，每项整数1–3；status/graded_at可选。
  不替换录音key、文件或学生元数据。
- 普通词汇抽查：progress/quiz:...保留recall_cn和sentence；
  vocab grade可写status(new/reviewing/mastered)、note、graded_at、
  quiz_history:[{quiz_id,date?,correct:boolean,note?}]；同quiz_id不重复累计。
- 旧词造句：progress/reencounter:<inputId>，kind:vocab_quiz，answers:[{word,vocabId,sentence}]。
  progress grade可写note/status/graded_at，给整组反馈；需要逐词判定时再写对应vocab.quiz_history。
  不用造句提交增加文章回顾次数。
- 熟识：vocab.manual_known为个人标记，review_articles按文章ID映射真实来源。
  review_count/familiar/familiarity_source由服务端推导，不由教学agent伪写；
  计数不等同教练mastered状态。
- 月度测试：progress/level_test:<inputId>，kind/type均level_test。
  status:draft/submitted/graded，answers下有listening/reading选择、speaking逐题blob、writing.text。
  speaking:[{question_id,part,blobKey,durationSec,mime}]；level-tests/前缀录音独立于shadowing。
  录音全部上传完成且submitted才允许批改。
  grade只允许assessment、status、graded_at。assessment严格为：
    {"scores":{"listening":<数值>,"speaking":<数值>,"reading":<数值>,"writing":<数值>},
     "overall_comment":"<真实总评>","level":"<真实水平判定>","next_month_advice":"<下月难度建议>"}
  scores遵守包中的score_scale；不带该字段时也不得自行编造教学分制/映射。
