## 正确的生词上报路径

正文点词→查看本句词义→加入生词本→同时写入本篇unknown_words并标记已上报。重复操作不增加同词计数；跨设备网络上传依然由上传按钮显式执行。不得再要求复制到逗号列表或点第二次上报。

未加词不自动伪造“零生词已确认”。移除旧难度表单后，也不填默认正好。主观体感的最终采集位置没有在本轮重新设计；数据缺项保持缺项，后端完成规则与新量化契约待界面确认后统一处理。
