# 学习工作台交付约定

本参考用于制作可接入的教学内容。真实部署接口可能升级，操作前读取当前项目的接口文档；Skill不携带地址凭证或个人数据库。

## 材料与字段

- `inputs`：日常包含唯一`id`、`date`、`title`、`body`、`level`、`word_count`、`audioKey`；正文保留段落和speaker。
- `sentences`：与输入包同`id`，`items[]`包含唯一句号`n`、`text`、`cn`、`audioKey`及适用的`speaker`。句文本必须与正文精确对应。
- `inputs.wordpack[]`：`{w,pos,cn,phrase?,n?}`。覆盖全文可点击词形；短语最长匹配，大小写/标点归一化，多义词按句号n取本句义。离线可用，不依赖在线词典。
- `comprehension[]`和`polysemy[]`：每题`id`、英文`q`、四个`options[{id,text}]`、`correct_option_id`、`explanation_en`；多义词题提供原句语境。
- `reused_vocab`必须来自真实生词本，3–5词且实际出现于新正文；材料不足时报告缺口，不编造学习历史。读后选其中2–3词造句，不要求每词必填；2.1当前实现与最新规则的接线状态分别核对。
- `chunks`与`discussion_prompts`依托本篇。全文与每句音频key都须有真实可解码文件，扩展名对应实际格式。
- `type:level_test`使用当前正式测试包schema，四项独立记录；不要把日常包直接改类型冒充完整月测。

## 生产与接入

1. 按真实学习状态与已确认方法制作内容，检查字数、句映射、词包语境覆盖、题目答案、声音指导与全部音频。
2. 保存制作档案：实际依据、声音提示词、模型/声线/版本、文件清单与校验结果。技术通过和用户试听通过分开记录。
3. 对真实库先读已有ID与对应音频，保留制作清单、摘要与回读证据后增量注入；不为每日任务复制整库或恢复过时备份/交接目录。相同ID不同内容拒绝覆盖；新教材用唯一新ID。原input01、Mina教材及学习历史保留；Mina仅隐藏入口。
4. 从实际接口回读字段与音频，并检查工作台读取；离线包交付不能写作“已注入”，Mac本机探测不能冒充其他agent云端连通。
5. 学生作答与录音从`progress/vocab/shadowing/dictation`实际读取；教练按现有字段级评分接口写回反馈，保留原答案，保护已有教练评分。

当前API形态：`/health`，需鉴权的`/api/records/{collection}`、`/api/import`、`/api/blobs/{key}`、`/media/{key}`、`/api/coach/pending`、`/api/coach/grades`。精确写入结构以当前部署文档为准；仅有这些路径不足以推断权限、token或评分payload。

## 不混淆教学与设备行为

四导航是今日学习、跟读录音、生词本、学习进度；正文连续排版，点词与句尾圆点共用卡片，逐句页已融入正文。

跟读实际录音开始3秒后播放参考，参考播完仍需手动结束；提前结束丢弃当前遍，完整多遍各自保存。播放调速不修改录音文件或真实录制时长。

设备学习数据显式上传/下载；教材只读且不混入学习同步。不能因教学“自动上报”而自动触发网络上传。没有真实作答就不写假完成记录或假成绩。

Mac Chrome与iPhone Safari真实播放、麦克风、持久化和同步需要各自验收。每次交付列实际环境/版本、用例和结果；模拟DOM、模拟麦克风与脚本HTTP结果明确标为非真机。

## 最新规划与实际接口的差别

每日至少两篇、约两小时是教学安排；旧听写不再作为后续必做任务，故事听力已并入学习者新命名的2.0前端审核，先审核再接业务后端。旧dictation记录保留，新教材不再必须附两段听写；前端样板可演示流程，不等于正式数据链路已经上线。

难度改为固定规则自动决定；现有i1_suggested/i1_final字段和界面中的教练字样尚未整体迁移。阈值和来源标识未定前不修改旧评分。录音量化需新结构方案，当前白名单拒绝未知grade字段；量化参考的字段描述不是可直接发送的API payload。

前端审核须保留现有完整功能，未改动的模块也不能在样板中省略。以完整工作台做增量，逐项核对水平测试四项/口语三部分/独立结果、日常答题反馈、录音多遍、生词抽查、同步与三趋势；用户明确变更的旧听写任务除外。审核夹具与正式学习记录隔离，不能把完整前端恢复说成正式后端已经接通。

学习者最新界面纠正：不得恢复独立逗号列表生词上报或难度提交表单。生词在正文加入词库时自动计入本篇；未产生体感或生词确认时不补默认值。固定2.1界面与最新确认才是审核基准，旧运行实现不是已批准教学流程。
