# 量化评价与十篇复评

2026-10-19，执行状态：学习者确认量化方向并允许开始。以下计算、证据和样本口径用于首轮工作；难度阈值、分数映射未定稿，正式自动决策尚未上线。

## 1. 日常难度的三项输入

| 指标 | 记录与计算 | 有效性要求 |
| --- | --- | --- |
| 生词率U | 本篇上报的去重生词单位数÷本篇word_count | 已确认生词上报；0个是有效值，未上报不是0；同词形去重、短语计1，不归并词形 |
| 理解正确率C | 已判定正确数÷有效题数，同时保留分子分母 | 对照该篇参考答案，题数大于0；0分不能误当缺数据；有争议题先核查 |
| 体感D | 太简单=-1、正好=0、吃力但能懂=1、太难=2 | 枚举编码，仅表示顺序，不能直接当等距量表求平均或随意加权 |

生词率2%–5%是既有目标，不宣称是通用教学标准。2.1旧程序使用U>8%或C<50%判hard，U<2%且C=100%判easy，其余hit；它只检查D已填写，不使用D的实际值。此处记录实际旧行为，不能将其当成学习者已确认的新阈值。

下一版规则需一张完整判断表，覆盖：缺数据、边界值、三信号一致、三信号冲突。尚待确定的是5%–8%如何处理、C的上下界、D在组合中的作用、单篇与连续多篇的使用方式。不要在未讨论前假定“任一困难就降级”或某一加权比例。

每条结果保留：文章ID、提交/批改版本、U的分子分母、C的分子分母、D原值、规则版本、命中的规则及结果；没有规则的组合标待确认，不默认hit。教练核查数据后由规则计算；原提交和旧结果保留，不静默覆盖。

## 2. 十个样本的首轮复评

本轮将“十个样本”按十篇不同ID的有效日常文章执行，而非十天、十次点击或同一篇的十遍录音。该口径随结果向学习者说明，可按其后续要求调整。

- 单篇需有有效word_count、生词上报、已核对理解结果和四选一体感，三项完整才计1篇。
- 排除月度level_test、演示/测试数据、缺项和题目待核查的文章；不能填默认值凑十篇。
- 同一文章跨设备、重传或重新提交只占1篇；按可追溯的最新有效版本分析。录音数量另记，不推动此计数。
- 首轮从本轮确认后的有效提交积累；历史样本如要回填，先说明使用区间和规则差异。此文件不是自动计数服务，不代表真实样本已累计。
- 达到10篇时整理三信号分布、信号冲突、耗时反馈及与学习者感受不符的案例，提出规则保留/修订建议；10篇是首轮复盘点，不宣称已证明算法准确。
- 未满10篇仍可与学习者讨论；修订用新版本记录，保留旧结果，避免把新旧阈值混称同一标准。

## 3. 录音先做可评估性检查

需要原始录音、对应原文、录音ID、参考音频版本/播放倍率及有效朗读区间。实际无法取得或分析音频时标“未评估”，不以文字转写代评发音。

检查参考音频串入、多人重叠、噪声和削波。参考音频盖过学习者或无法分辨声音来源时，该部分不可评分，不能把播放器的朗读算作学习者表现。

前三秒准备时间、手动结束前的尾部静音排除；自然句间停顿和换人停顿保留语境判断。分段不明时记录不确定，不直接扣分。

## 4. 跟读指标口径

| 项目 | 计算与输出 | 证据/边界 |
| --- | --- | --- |
| 内容完整度 | (原文词数N－确认漏读数D)÷N | N>0；替换词另记，不又算漏读；对齐不明则不输出确定比例 |
| 文本偏差 | 分列确认替换S、多读I、漏读D；附(S+D+I)÷N | 只作偏差统计，可超过100%，不直接等同发音正确率；重启/重复与插入做事件关联，防止重复扣分 |
| 发音问题 | 经音频确认的词与时间点；具备逐词覆盖时才算问题词数÷实际评估词数 | 标明覆盖范围；只查疑似词时不能把未查词算正确或外推全文 |
| 卡顿 | 逐次标记非自然停顿的起止、总时长及每百个实际朗读词次数 | 正常停顿不计；时长阈值待校准，不先把所有静音视为卡顿 |
| 重启/非必要重复 | 事件数、所处词句、每百词次数 | 自我纠正单列；同事件可有多个描述，但总分映射需防止重复处罚 |
| 速度 | 实际朗读词数÷有效朗读区间分钟数 | 区间包括内部停顿，排除准备和尾部静音；记录所选倍率，不设越快越好 |
| 节奏/重音 | 影响理解的具体词句与时间点 | 目前只做可观察描述，不伪造声学精度或要求逐音复制示范 |

语音识别产生疑似替换、漏词时，先复核原始音频，再分类：实际读错、识别误差、参考串音、无法确定。无法确定项不自动计为错误，也不算已确认正确。若仅能可靠评估一段，就只报告该段。

以上文本对齐用于录音分析，不恢复已取消的学生逐字听写练习。

## 5. 分数与反馈

现有三个1–3分维度保留作兼容目标；完整度百分比、确认发音问题率、卡顿/重启等到1/2/3分的映射待学习者讨论。缺少覆盖或分档依据时先交付指标和证据，正式分数字段保持未评分，不填0或凭印象填2。

每遍独立保存：录音ID、原文/音频版本、分析覆盖、质量限制、逐项指标、时间点证据、待核查项、评分规则版本，以及一个最优先改进点和可操作的重练方法。重复录制不覆盖上一遍；同一段表现不在多个维度反复扣分。

纠正示例必须来自该次真实问题；教学示例可另给，但明确标示为示例，不作为学习者已犯错误写回。月度自由口语没有固定原文，不能套用跟读的漏读/覆盖率公式；写作与自由表达也需各自量表。

## 6. 技术落地边界

当前2.1接口还没有以上全部结构化分析字段，且评分写入会校验白名单。不能擅自往progress.grade塞difficulty或未定义metrics，也不能把所有指标硬塞成现有三个分数冒充已接入。

正式实现前需完成字段方案、规则版本、原文与音频对齐能力验证、隔离数据测试以及Mac Chrome/iPhone Safari实录回归；原作答和录音保持不变。本文定义教学执行口径，不声明已有自动语音评测服务。
