# 每日教学入口

本Skill编排工作，教学决策以[english-learning-coach](../english-learning-coach/SKILL.md)为唯一依据。按顺序读取下面实际用到的Skill；“调用”指当前agent读取并执行，不要求创建子agent或新对话。

## 开始与恢复

先读[执行契约](references/workflow.md)，以及项目`AGENTS.md`、`docs/cloud.md`，确认当前正式环境。读取本地目标日`运行记录.json`与云端实际教材，不能依赖上次聊天记忆。按当前用户profile中的时区计算日期；定时任务须明确目标日，启动后固定目标日，重试不因跨日改编号。目标日准备至少两篇、约两小时的学习安排；时间不是后台播放或强制完成门槛。

每日23:00任务先向学习者请求本次目标日的具体许可：是否允许仅为教材音频生成与内容核对读取集中凭证库中的Gemini TTS Key。收到明确许可前不读取或调用该凭证；先完成可独立进行的云端只读核对、选材、文本制作与固定清单，保存进度等待回复。已有Key不得要求学习者再次在聊天或终端输入。许可只对该次任务和固定目标日生效，不推定为以后每天的长期授权。

使用[发布技能](../english-learning-publish/SKILL.md)的`snapshot`命令取得最新学习状态。只读正式资料，不重跑迁移、开户或改密码。当天已经达到两篇合格新教材时结束制作；仅一篇时补一篇。先核对文章而非只数`date`，排除Mina、工程夹具、月测和不完整包。

首次为当天确定尚缺的文章ID，写入运行记录后保持固定。重试沿用同一包、音频key和来源，不重新生成第二套；远端已导入时先回读核对再继续。异常退出后以云端记录为准恢复；发布工具的同日锁防止本机并发发布，锁不自动过期，解除前必须确认旧运行已停止。

## 技能链

1. [english-learning-coach](../english-learning-coach/SKILL.md)：从实际已上传的表现、生词本和近期题材写本日选材依据；阈值未定不擅自调难度。
2. [english-learning-materials](../english-learning-materials/SKILL.md)：优先人类分级素材，制作完整正文、词包、题目、翻译及来源档案。每篇写一个`lesson.json`。
3. [english-learning-audio](../english-learning-audio/SKILL.md)：按场景制作全文与句音，保存声音档案。缺授权/额度或新风格未试听时标阻塞；不退回被否定的系统朗读方案。
4. [english-learning-publish](../english-learning-publish/SKILL.md)：执行技术校验、内容核对、私有音频上传、增量导入、正式回读。每篇分别发布，第二篇失败时保留第一篇结果。只有回读全部通过才计入当天已注入。
5. [english-learning-feedback](../english-learning-feedback/SKILL.md)：仅处理真实新增且可评估的作答；没有待批作答就跳过。此环节失败不撤销已发布的教材，不编造评分或妨碍下一次补齐教材。

每步将实际产物路径、校验摘要和阻塞原因更新到当日运行记录。下游必须重新读取文件、核对输入摘要，不能只相信上游一句“完成”。正文变更后词包、题目、音频和校验均须重核；已发布教材不可同ID改写。

## 收尾

汇报日期、实际新增标题/ID、每篇完成或缺项、真实检查环境、反馈处理数量和待学习者确认事项。未发布的草稿不计入两篇。自动化本身未完成真机验收；Mac Chrome/iPhone Safari测试必须另有实际证据。

日常任务不开发前后端、不修改冻结UI，不创建新的月测或尚在审核的故事功能，不启用付费服务或修改计费。只使用现有已授权服务；需当次同意的凭证库不能因为定时任务而跳过授权。无人值守遇到此类阻塞时保存进度并报告。
