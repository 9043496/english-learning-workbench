# 实际作答反馈

先读[教学Skill](../english-learning-coach/SKILL.md)，按任务读教学基线及量化评价口径。通过发布Skill的snapshot或当前受控教练接口读取真实上传数据，核对正式学习者与材料版本。设备尚未手动上传的缓存不可见，不宣称已经批改。

先判断是否有新增/变化的有效作答；结合已有graded_at、status、原答案hash/录音key，避免每天重复追加同一quiz_history或重复评分。不同录音遍数分别处理。没有待批作答时记录skipped_no_submissions，不生成作答或分数。

## 核查与反馈

- 日常理解/多义词题：对照实际选项和教材参考答案，给正文证据；有争议先核查题目，不把争议算学生错。保留原answers。
- 旧词造句/普通抽查：使用真实原句及回忆答案。旧词未选的项不判为已会用；出现12篇的熟识记录不等同教练mastered。判掌握规则未定不凭提交升级。
- 跟读：必须取得并实际分析本遍原音、原文和参考版本，核对准备3秒、结束尾静音、串音和噪声。按量化参考列确认漏读/替换/多读、已核实发音问题、卡顿与时间点证据，给一个优先改进点。ASR误差不是学生发音错误；无法分辨学生与参考音时标不可评估。1–3分映射未定，先交付证据，不凭印象造分。
- 月测：仅批改真实已submitted、录音均可读取的四项包；听读选项按包核对，口语Part1/2/3和写作按实际素材及已批准score_scale/量表。没有量表不发明雅思/CEFR映射。月测不混入日常三趋势。

## 写回边界

精确grade白名单先读当前项目接口和cloud SQL/Worker；教学参考中的metrics不是可直接发送的API字段。用当前模式的受控POST /api/coach/grades逐字段追加；云模式可用cloud/tools/coach-client.mjs，本地模式用自身私有配置鉴权，保留学生原答案和录音；禁止修改已存在成绩来凑趋势。未知量化字段不要绕过接口直写数据库。

接口不能表达的真实分析保存在项目私有_tmp或经授权的反馈成品中，并报告“尚未写回”，不塞假分或滥用无关字段。正式录音未评估时不改graded状态。写回成功后重新读取目标记录核对grade与原答案hash；失败不重复盲写，尤其quiz_history用稳定quiz_id去重。

十篇复评按量化参考计有效日常文章；缺少生词确认、主观反馈或有效理解结果不补默认值。达到十篇时整理真实分布和阈值建议，与学习者对齐，不自行变更教学规则或界面。
